# Credit Card Customer Churn Prediction

This project predicts whether a customer will churn (stop using services) in a credit card portfolio, using machine learning, fastAPI and Streamlit for deployment.

## 📌 Features
- Data analysis & visualization
- Logistic Regression model for churn prediction
- REST API using FastAPI
- Interactive UI using Streamlit

## 🧠 Tech Stack
Python, Pandas, Numpy, Scikit-learn, FastAPI, Uvicorn, Streamlit
